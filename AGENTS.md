# Project Instructions

## Inspect Before Implementing

Before starting any UI or code work, read the existing project first. Check:

- Project structure and relevant directories
- `package.json` and installed dependencies
- Framework and build tool
- Application entry point and routing
- Existing components and UI library
- Styles, design tokens, and related screens

Summarize what is already present before proposing or changing code. Reuse the
project's existing structure, components, styles, and UI stack. Do not add a
new UI stack when the project already has an established one.
